# X Angels Investment Lab

Учебный практикум X Angels · Astana Venture Club · Axiom Capital: анонимный кейс, выбор суммы, инвестиционный тезис и разбор. Приз получают за качество анализа; правильной суммы нет.

## Что изменено

- Тексты сокращены, основные шрифты увеличены до 18–21 px, служебные подписи — от 14 px.
- При отправке обязателен только инвестиционный тезис: от 1 непробельного символа.
- Имя или псевдоним, почта, риск и вопросы перед сделкой необязательны. Если почта указана, проверяется её формат.
- Разбор и материалы доступны без заполнения формы и отправки ответа.
- Телефон и отдельный Gmail-адрес клуба удалены. Для связи оставлена ссылка на Telegram.

## Загрузка на GitHub Pages

1. Распакуйте ZIP и загрузите **содержимое** папки `x-angels-investment-lab` в репозиторий. `index.html` должен находиться в корне рядом с `app.js`, `styles.css` и логотипами.
2. Откройте **Settings → Pages**, выберите публикацию из ветки `main` и папки **/(root)**.
3. Откройте адрес, который покажет GitHub. Проверьте сайт с телефона.

Сборка и npm не нужны. Относительные пути подходят для публикации в подпапке. Не загружайте один ZIP вместо распакованных файлов.

## Приём ответов

Ответы направляются на рабочий адрес **info@astanaventure.com** через FormSubmit. Адрес сохранён в `RECIPIENT` в `app.js`. Это открытая настройка клиентского сайта: посетитель может увидеть её в исходниках.

После публикации отправьте тестовый ответ, подтвердите активацию в письме FormSubmit на рабочей почте, затем повторите тест и проверьте получение. Код проверен с имитацией ответов сервиса; реальная доставка на почту не проверялась. Уведомление на сайте подтверждает приём сервисом, а не доставку письма.

Имя не требуется. В ответе без имени организаторы увидят «Участник без имени» и номер ответа. Для определения автора конкурсного тезиса посетителю предлагается указать имя или псевдоним. Незаданные почта, риски и вопросы не добавляются в запрос.

Нажатие «Продолжить без отправки» не передаёт ответы организаторам. Черновик хранится в браузере участника. «Начать заново» очищает локальную копию; ранее отправленное письмо остаётся у организаторов. При неудачной отправке текст остаётся в форме, а повторная попытка использует тот же номер ответа.

## Публичный репозиторий

В архиве нет паролей, ключей API, ответов участников, персонального телефона или подписи автора. Оставлены корпоративные названия, логотипы, рабочая почта для формы и приглашение в Telegram. Публикация исходников сделает эти материалы общедоступными.

Не добавляйте в репозиторий выгрузки ответов, реальные персональные данные, `.env`, ключи или файлы базы данных. `.gitignore` исключает распространённые файлы такого типа; это не заменяет проверку добавляемых файлов.

## Файлы и проверка

- `index.html` — кейс, тексты, форма, разбор и ссылка на Telegram.
- `styles.css` — шрифты, цвета и адаптивная вёрстка.
- `app.js` — отправка, необязательные поля и локальный черновик.
- `scripts/check.mjs` — проверка логики без реальных писем.

При установленном Node.js 22+ запустите:

```bash
node scripts/check.mjs
```

Проверяются все четыре суммы, тезис из одного символа, необязательные поля, формат почты, пропуск формы, состав запроса, повторы, ошибки доставки и восстановление черновика. Внешний вид в браузере нужно проверить после публикации.

Все цифры, команда и условия кейса вымышлены. Ссылки на источники — в `SOURCES.md`.
